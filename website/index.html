systemd-inferenced · v0.1.0

A pure-Rust hardware arbiter for Linux AI.

systemd-inferenced brings unified resource scheduling to local AI workloads on Linux across discrete GPUs, NPUs, UMA/APUs, and CPU matrix extensions. Operating as an intelligent gateway between systemd and competing inference engines, it eliminates VRAM contention and host memory exhaustion through dynamic demand paging, socket activation, and cooperative model offloading. 100% pure Rust. Zero C dependencies.

01Why systemd-inferenced?

In modern Linux, GPU and accelerator compute are completely detached from OS cgroups and process schedulers. Heavy inference runtimes allocate greedy memory pools up front, causing CUDA out-of-memory panics, desktop compositor stutter, and system bus starvation.

  • Heterogeneous Hardware Fabric. Unified discovery across discrete GPUs (/dev/dri/renderD*), NPUs (/dev/accel/*, Hailo), UMA APUs, and CPU matrix extensions (Intel AMX, AVX-512).
  • Unix Zero-Copy Data Plane. Model distribution using sealed memfd_create and SCM_RIGHTS file descriptor passing. $N$ processes share 1 copy of physical RAM.
  • Systemd Control Plane. Native Varlink IPC (io.systemd.inferenced1), socket activation adopting pre-bound fds, and cgroups v2 two-tier preemption.
  • systemd-sentry Triage Enclave. Dedicated out-of-band compute slice pinned on NPU or CPU matrix cores with MemoryMin=2G, surviving catastrophic discrete GPU driver panics.

02Torvalds & Unix Philosophy

Rather than building a bloated virtual memory manager in userland, systemd-inferenced adheres strictly to the Unix doctrine:

  • Everything is a File Descriptor. Weights are passed as sealed memory file descriptors directly over Unix sockets. The daemon never buffers multi-gigabyte tensors in userland memory.
  • Kernel Memory Delegation. Uses madvise(Advice::LinuxDontNeed) to let the kernel's zswap reclaim inactive memory instantly without disk swapping.
  • Composable Unix Stream Filters. Standard stream piping: stdin | inferenctl exec <model> > stdout. Zero HTTP or curl boilerplate required.

04Quickstart

Install via the zero-trust installer:

git clone https://github.com/syntropd/inferenced.git
cd inferenced
sudo ./install/install.sh
sudo systemctl enable --now systemd-inferenced.socket

Pipe standard streams into local AI models:

journalctl -u nginx.service -n 50 | inferenctl exec qwen2.5-coder:7b > /var/log/triage.txt
