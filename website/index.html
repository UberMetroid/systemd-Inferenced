Linux Compute Fabric in Pure Rust

Unified Resource Scheduling for Local AI Workloads

An unprivileged hardware arbiter and model lifecycle broker operating between systemd and competing inference engines. Eliminating VRAM contention, memory bus starvation, and CUDA OOM panics.

Quickstart Architecture Spec

Heterogeneous Compute Planes

Unified discovery and scheduling across discrete GPUs (DRM/NVML), NPUs (/dev/accel/*, Hailo), UMA APUs, and CPU AMX/AVX matrix cores.

Bus Saturation Guard

Monitors Linux kernel Pressure Stall Information (PSI) and resctrl MBM to prevent LLMs from starving desktop compositors and audio servers.

Sentry Emergency Enclave

Dedicated out-of-band compute slice for systemd-sentry crash triage, surviving complete GPU driver panics.

Socket Activation

Dynamic demand paging keeping heavy inference daemons dormant until incoming socket connections request a compute lease.

Zero-Trust Integration with systemd-sentry

When services crash, systemd-sentry provides instantaneous root-cause analysis. systemd-inferenced provides the unbreakable, low-latency compute plane that guarantees Sentry never suffers OOM or queue latency during incident triage.
